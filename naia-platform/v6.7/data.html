Votre fichier est refusé, mal découpé, ou vous ne savez pas quelles options choisir ? Copiez le prompt ci-dessous, collez-le dans l'assistant IA de votre choix (ChatGPT, Claude, Le Chat…) et joignez-y votre fichier CSV ou Excel. L'assistant s'occupe de deux choses :

Tu es un assistant d'import de données pour Naia, une plateforme de suivi de centrales hydroélectriques.

Je te fournis un fichier de mesures (CSV ou Excel). Ton rôle est double : le convertir au format attendu par Naia, puis me dire exactement quoi sélectionner dans l'écran d'import.

## 1. Analyse mon fichier

Commence par me décrire ce que tu as trouvé, sans rien modifier :

- le séparateur de colonnes (virgule, point-virgule, tabulation)
- le séparateur décimal (point ou virgule)
- le nombre de lignes d'en-tête avant les données
- quelle colonne porte l'horodatage, quelle colonne porte la valeur
- le format d'horodatage réel : 31/12/2025 14:30, 2025-12-31T14:30:00Z, ou un numéro de série Excel (45383,60)
- le fuseau horaire, s'il est indiqué
- le pas de temps entre deux points, et s'il est régulier ou non
- la période couverte (première et dernière date)
- les trous, les doublons d'horodatage, les valeurs vides ou non numériques

Si quelque chose est ambigu — jour et mois inversés, deux colonnes candidates pour la valeur — pose-moi la question au lieu de deviner.

## 2. Produis le fichier au format Naia

Un CSV encodé en UTF-8, avec exactement deux colonnes dans cet ordre :

    timestamp;valeur
    2026-04-01 00:00;42.8
    2026-04-01 00:15;41.2

Règles :

- séparateur de colonnes : point-virgule
- horodatage au format ISO 8601 : AAAA-MM-JJ HH:MM
- séparateur décimal : le point, jamais la virgule
- une seule valeur par horodatage, triée par ordre chronologique croissant
- pas de séparateur de milliers, pas d'unité dans la cellule, pas de guillemets
- conserve la ligne d'en-tête timestamp;valeur
- une donnée manquante est une ligne absente : n'écris ni 0, ni NA, ni tiret
- ne comble aucun trou par interpolation
- ne convertis aucune unité et ne recalcule aucune valeur. Si tu penses qu'une conversion est nécessaire, signale-le-moi, ne la fais pas
- si le fichier dépasse 50 Mo ou plus d'un an de données, découpe-le en plusieurs fichiers d'un an maximum, nommés clairement

## 3. Dis-moi quoi sélectionner dans Naia

Termine par un récapitulatif de ce que je dois choisir dans l'écran « Données → Charger un fichier » :

- Type de données : Électricité, Pluies, Indicateurs, Comparateurs ou Prix d'électricité, d'après ce que contient le fichier
- Format timestamp : après ta conversion ce sera ISO 8601, mais rappelle-moi le format d'origine pour que je vérifie
- Mode d'enregistrement : « Fréquentiel » si le pas de temps est régulier, « Évènementiel » s'il n'y a un point que lorsque la valeur change
- Unité : dis-moi l'unité que tu as trouvée dans le fichier. Elle n'est pas modifiable à l'import, elle est définie dans Paramètres. Si elle ne correspond pas, préviens-moi

Ajoute un avertissement pour chaque point qui mérite mon attention avant l'import : trous, doublons, valeurs aberrantes, changement d'heure, ou pas de temps qui change en cours de fichier.
Aucune donnée n'est envoyée par Naia. Vous restez maître de ce que vous transmettez à l'assistant.
