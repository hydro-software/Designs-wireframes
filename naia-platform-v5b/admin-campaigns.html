Campagnes d'acquisition
Les campagnes sont des codes d'attribution marketing à durée limitée — salons, webinaires, mailings — attachés à chaque lead capturé (FR-LEAD-1). Le code apparaît sur les leads, les codes de jeu (FR-GAMECODE), les promotions éligibles (FR-PROMO-10), et alimente l'analytics du funnel de conversion (FR-DEMO-8). Distinct des codes de parrainage qui sont durables et liés à une association (Community FR-PARRAINAGE-4).

Modèle d'attribution. Chaque lead capturé porte un campaign_code (FR-LEAD-1) qui pointe vers une de ces lignes. Les codes de jeu (FR-GAMECODE-1) et les promotions éligibles (FR-PROMO-10) en héritent. L'analytics du funnel (FR-DEMO-8) trace les conversions par campagne, et le MRR attribué remonte dans le bloc Acquisition funnel du dashboard admin (FR-PAD-1). Les campagnes terminées restent accessibles indéfiniment pour les besoins de reporting historique.

À implémenter dans le PRD : une famille FR-CAMPAIGN formalisant les attributs ci-dessous (code, libellé, type, période, statut, propriétaire) + la table subscription.campaigns (la maquette précède la spec PRD, à confirmer).
